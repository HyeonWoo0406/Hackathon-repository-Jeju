# 로컬 개발 서버 실행 안내

이 안내는 개발 PC에서 로컬로 실행하는 방법입니다. 고정된 공개 데모 주소나 외부 터널은 제공하지 않습니다.

## 준비

1. Python 3.11 이상과 Node.js/npm을 설치합니다.
2. `competitions/제주 프로그램` 폴더에서 가상환경을 만들고 백엔드 의존성을 설치합니다.
3. `.env.example`을 `.env`로 복사하고 필요한 경우 발급받은 본인 키를 입력합니다. `.env`는 커밋하지 않습니다.
4. 프론트엔드 의존성을 설치하고 빌드합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
Copy-Item .env.example .env
Push-Location frontend
npm ci
npm run build
Pop-Location
```

## 실행

`competitions/제주 프로그램` 폴더에서 실행합니다.

```powershell
.\.venv\Scripts\python.exe run.py
```

브라우저에서 `http://127.0.0.1:8765`를 엽니다. 종료하려면 실행 중인 터미널에서 Ctrl+C를 누릅니다. 기본적으로 로컬 주소에서만 사용하세요.

API 키는 소스 코드, 문서, 이슈, 로그 또는 제출 파일에 입력하지 마세요. 사용할 자료의 접근 권한과 최신 이용 조건은 제공처에서 직접 확인해야 합니다.

## 검증

```powershell
.\.venv\Scripts\python.exe -m pytest backend\tests -q
npm --prefix frontend test
npm --prefix frontend run build
```

데이터베이스·수집 기록은 `runtime/` 또는 `data/` 아래에 생성될 수 있으며 Git에서 제외됩니다. 실제 매출 또는 개인 데이터가 포함된 데이터베이스를 공유하지 마세요.
