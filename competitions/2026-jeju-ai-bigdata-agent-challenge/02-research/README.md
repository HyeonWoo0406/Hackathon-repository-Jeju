- **필수:** 제주빅데이터센터 또는 제주데이터허브 데이터 1종 이상.
- 제주데이터허브 공개 데이터는 [jejudatahub.net](https://jejudatahub.net/)에서 확인합니다.

- 센터 보유 데이터 명세: [제주데이터허브 - 제주빅데이터센터 메뉴](https://jejudatahub.net/center/data)
