## 실행 환경 및 데이터 규정

- 시연 대상 센터 PC: Intel Core i7-8700, GTX 1060, RAM 32GB
- 참가자 전용 데이터목록 XLSX는 GitHub 등 외부 저장소에 올리지 않는다. 해당 파일에서 추출한 내용도 공개 저장소에 포함하지 않는다.
- 제출물의 권리는 제주빅데이터센터에 귀속된다.
- 코드에 API 키나 개인정보를 포함하지 않는다.
- 상금 총액: 5,000,000원

일정·제출 방식은 변경될 수 있으니 제출 직전에 공식 페이지를 다시 확인한다.
