## 참가 규칙

- 개인 또는 팀으로 참가할 수 있으며, 일반인·학생 등 누구나 참가할 수 있습니다.
- 팀은 최대 5명이며, 동일인은 개인 또는 복수 팀에 중복 등록할 수 없습니다.
- 팀 빌딩 페이지에서 팀을 만든 경우 제출 전에 팀장이 대회 안내 페이지에서 **팀으로 전환**해야 합니다.

## 제출 방법 및 필수 제출물

제출 경로는 DAKER의 **[갤러리] - [기획서 및 최종 결과물 제출]**입니다.

1. **AI Agent 기획서 1부:** 최대 15페이지. 분석 주제와 AI 분석 목표, 서비스·핵심 기능, Agent 역할·목표·Workflow·모델·Tool/API·자율 수행 범위, 데이터 활용 계획, 개발·탑재 계획을 담습니다.
2. **최종 결과물 ZIP:** 아래 자료를 포함합니다.
   - 실행 소스 코드, Prompt, Tool/API 연동 및 데이터 처리 코드, 사용 모델·라이브러리 정보
   - README, 설치·실행 절차, 의존성 목록, 환경변수 예시, 사용자 매뉴얼, 오류·제약사항
   - 필수 데이터 사용 내역, 출처·이용조건, 전처리·분석 흐름, 외부 데이터·오픈소스 목록
   - 문제 정의, Agent 구조, 주요 기능, 실행 결과, 검증 방법·한계, 센터 활용 방안

최종 제출에는 사용 AI 모델과 AI 활용 범위, 외부 API·서비스, 외부 데이터, 오픈소스 및 외부 코드를 명시해야 합니다.

## 평가 방식과 기준

최종 평가는 **내부 전문가 70% + ELO 기반 참가팀 상호 평가 30%**입니다. 상호 평가는 최종 제출을 완료한 팀을 대상으로 합니다.

ELO 평가에서는 두 제출물을 비교 투표합니다. 본인 팀의 제출물은 투표 화면에 표시되지 않으며, 최소 투표 횟수에 미달하면 투표와 득표 결과가 평가에 반영되지 않습니다(No Vote, No Gain).

| 전문가 평가 항목 | 배점 | 평가 내용 |
|---|---:|---|
| 분석 주제의 타당성과 창의성 | 15 | 주제의 참신성, 활용 목적의 명확성 |
| 필수 데이터 활용 적절성 | 20 | 지정 데이터 1종 이상의 실질적 활용, 분석·처리 방법 |
| AI Agent 기술성 및 완성도 | 25 | 목표에 따른 도구·데이터 활용, 주요 기능의 안정적 수행 |
| 편의성 및 실용성 | 25 | 사용자 편의성, 실제 서비스 활용 가능성 |
| 결과 신뢰성 및 재현성 | 15 | 근거·한계의 명확성, 코드·매뉴얼을 통한 재현 가능성 |
| **합계** | **100** | |

동점이면 AI Agent 기술성 및 완성도, 편의성 및 실용성, 필수 데이터 활용 적절성 순으로 우선 선정합니다. 그래도 같으면 심사위원 합의 또는 재심사로 결정합니다.

## 데이터·보안·저작권 규정

- 제주빅데이터센터 또는 제주데이터허브의 데이터 중 1종 이상을 반드시 활용합니다.
- 참가자 전용 `제주데이터허브 데이터 목록_20261105.xlsx`는 DAKER 외부 배포 및 제3자 제공이 금지됩니다. GitHub 등 외부 저장소에 업로드하거나 공개하지 않습니다.
- 개인정보, 금융정보, 인증정보, API Key 등 민감정보를 코드·발표자료·영상에 포함하지 않습니다.
- 외부 데이터/API는 적법하게 활용하고 출처를 표시합니다. 외부 서비스의 이용약관과 보안 기준을 준수하며, 외부 서비스 의존성을 계획·매뉴얼에 명시합니다.
- 데이터·이미지·코드·모델은 적법하게 사용할 수 있어야 합니다. 타 공모전 수상작 또는 기존 공개·상용화 결과물을 그대로 제출할 수 없습니다.
- 표절, 저작권 침해, 허위 기재 등 부정행위는 평가 제외·수상 취소로 이어질 수 있습니다.

## 제출물 검증 및 소유권

운영진은 정상 작동과 제출 내용의 사실 확인을 위해 코드 실행을 요청하거나 실행환경·모델·데이터·API 이용 내역을 추가로 요청할 수 있습니다. 제출물과 발표·시연이 크게 다르면 평가에 반영될 수 있습니다.

모든 결과물은 제주빅데이터센터에 귀속됩니다. 시상작은 제작자 이름 또는 팀명으로 센터에서 제공될 수 있습니다.

## 상금 및 수료증

총 상금은 500만 원입니다. 대상 1팀 300만 원(제주특별자치도지사상), 최우수상 1팀 100만 원(제주테크노파크원장상), 우수상 2팀 각 50만 원(제주테크노파크원장상)입니다. 당선작이 없으면 시상하지 않을 수 있으며 상금은 원천징수 후 지급됩니다.

모든 참가자에게 제주테크노파크 수료증을 발급합니다. 요청 시 향후 5년간 재발급할 수 있으나, 부정행위가 확인되면 발급·재발급이 취소 또는 제한될 수 있습니다.
