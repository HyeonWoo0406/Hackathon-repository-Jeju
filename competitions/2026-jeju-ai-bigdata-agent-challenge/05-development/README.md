# 개발 및 기술 자료

## 센터 실행 환경

센터 Agent 운영 PC 최소 사양은 **Intel Core i7-8700, NVIDIA GTX 1060, RAM 32GB**입니다. 외부 서비스가 필요한 경우 의존성과 센터 환경에서의 실행 조건을 기획서와 매뉴얼에 명시합니다.

## ZIP에 포함할 개발 자료

- Agent 실행 코드, Prompt, Tool/API 연동 코드, 데이터 처리 코드
- 사용 모델과 라이브러리 정보
- 설치·실행 절차, 의존성 목록, 환경변수 예시, 사용자 매뉴얼
- 오류와 제약사항, 데이터 출처·이용조건, 전처리·분석 흐름
- 외부 데이터·API·서비스, 오픈소스와 외부 코드 목록

운영진이 제출물의 실행과 사실관계를 확인할 수 있으므로, 코드·매뉴얼·시연이 일치하도록 관리합니다. API Key·개인정보 등 민감정보를 저장소나 결과물에 넣지 않습니다.

프로그램 소스는 복제하지 않고 저장소 루트의 [`제주 프로그램/`](../../../제주%20프로그램/README.md)을 기준으로 관리합니다.
