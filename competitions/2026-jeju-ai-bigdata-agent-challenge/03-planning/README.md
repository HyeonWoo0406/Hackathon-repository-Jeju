# 아이디어 및 기획

필수 제출물은 제주빅데이터센터·제주데이터허브 데이터를 활용한 분석 주제와 AI Agent 구현 계획을 담은 **15페이지 이내 기획서 1부**입니다.

기획서에는 다음 항목을 포함합니다.

1. **구현 목표:** 분석 주제와 AI를 활용한 데이터 분석 목표
2. **서비스 제안:** 데이터 활용 개요, 핵심 기능, 편의성, 분석 데이터 활용 방안
3. **Agent 개발 구성:** Agent의 역할·목표·Workflow, 사용 모델, Tool/API, 판단 및 자율 수행 범위
4. **데이터 활용 계획:** 필수 데이터명·출처·활용 항목, 수집·전처리 방법, 이용조건
5. **개발·탑재 계획:** 구현 범위, 기술 환경, UI 구성, 센터 실행환경, 외부 서비스 의존성

문제 정의, 대상 사용자, 요구사항, 사용자 흐름과 MVP 범위를 이 폴더에 기록합니다. 공식 대회 요구사항과 팀에서 확정한 기획을 구분하고, 미확인 가정은 확정 사실처럼 쓰지 않습니다.
