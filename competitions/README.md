# 자료 관리

해커톤마다 폴더를 하나씩 만들고, 해당 대회와 관련된 자료만 그 안에 보관합니다.

## 폴더 구성

현재 정리된 제주 대회 자료: [`2026-jeju-ai-bigdata-agent-challenge/`](2026-jeju-ai-bigdata-agent-challenge/README.md)

폴더 이름은 `<연도>-<대회명>`으로 작성합니다. 예: `2026-cheongdo-vibe-coding`

```text
competitions/
└── <연도>-<대회명>/
    ├── README.md          # 주최, 일정, 주제, 공식 링크
    ├── 01-announcements/  # 공고, 규정, 안내 자료
    ├── 02-research/       # 문제 조사, 참고 자료, 인터뷰
    ├── 03-planning/       # 아이디어, 기획, 요구사항
    ├── 04-design/         # 화면, 디자인, 발표 자료
    ├── 05-development/    # 구현 및 기술 자료
    └── 06-submission/     # 제출본 및 결과물
```

## 관리 기준

- 자료는 관련 대회 폴더 안의 알맞은 항목에 저장합니다. 대회 간 자료를 한 폴더에 섞지 않습니다.
- 문서와 파일 이름은 내용을 알아볼 수 있게 작성하고, 날짜가 중요하면 `YYYY-MM-DD`를 앞에 붙입니다.
- 공식 자료는 출처나 원본 링크를 함께 기록합니다.
- 비밀번호, API 키, 개인정보 등 공유하면 안 되는 정보는 저장하지 않습니다.
- 대회 폴더를 추가할 때 이 구성과 기준을 따릅니다.
