# 토스플레이스 + Square 디자인 적용 1차

적용일: 2026-11-16

## 선택한 방향

사용자가 선택한 토스플레이스(레퍼런스 1)와 Square(레퍼런스 4)를 기준으로 한다.

- 토스플레이스: 짧은 결과 설명, 읽기 쉬운 수치, 밝은 중립 배경과 제한된 파란색.
- Square: 메뉴/작업 영역 구분, 넓은 비교 그래프, 지표별 상세 표.
- 기존 크림색·초록색 팔레트는 제거했다.
- 외부 제품의 로고와 화면 이미지는 앱에 사용하지 않았다.

## 구현 범위

- React + TypeScript의 기존 프론트엔드를 수정했다. Vite와 Node.js 개발 도구 구성을 유지했다.
- `WorkspaceLayout.tsx`: 공통 헤더, PC 사이드 메뉴, 태블릿/모바일 상단 메뉴.
- `App.tsx`: 공통 작업 레이아웃 연결. 자료 삭제는 화면 아래 자료 관리 행동으로 통일.
- `style.css`: 중립/파란색 토큰, 폼, 버튼, 표, 그래프, 질문창, 로딩, 반응형 구성.
- `Setup.tsx`: 선택한 동네와 정류소의 사용 목적 설명.
- `Sales.tsx`: 대상 주를 먼저 펼치고 기준 주는 접어서 표시. 주별 입력/휴무 상태 개수 제공.
- `Report.tsx`: 주간 요약 → 변화율 → 요일별 흐름 → 지표 상세 → 근거 순으로 재구성.
- 모바일에서는 축소한 SVG 대신 요일별 읽기 가능한 상세 행을 사용한다. 표도 항목별 세로 구성으로 전환한다.
- null은 자료 없음으로 표현하고 값이 없는 항목에 단위를 붙이지 않는다.
- 인쇄용 근거와 기존 날씨 비교 정보를 별도로 유지한다.
- 질문 패널의 모바일 너비와 바로가기 터치 영역을 수정했다.
- 검수용 가상 화면도 같은 공통 레이아웃을 사용한다.

백엔드, API 계약, 계산, 수집, 데이터베이스, 실행 파일은 변경하지 않았다.

## 검증 결과

- 최초 설정 / 매출 입력 / 정상 결산 / 자료 부족 결산의 4개 상태를 320, 390, 820, 1024, 1440px의 5개 너비에서 확인했다. 20개 조합에서 페이지 가로 넘침이 없었다.
- 390px의 결산 표는 가로 스크롤 없이 세로 구성으로 보인다.
- 자료 부족 검수에서 값 6개가 단위 없는 자료 없음으로 표시된다.
- 390px 질문 패널: 왼쪽 12px, 오른쪽 363px, 문서 표시 너비 375px. 기존 왼쪽 -3px 문제를 해소했다.
- 모바일 질문 바로가기 높이 44px.
- 브라우저 오류 로그 없음.
- 프론트엔드 기존 테스트 13개 통과, 타입 검사와 프로덕션 빌드 성공.
- 검수 페이지 TypeScript 검사 성공.

스크린샷은 가상 결산 데이터로 캡처했다. 실제 분석 정확성이나 서버 연동 전체를 검증한 결과는 아니다.

- 실제 인쇄/PDF의 페이지 분할.
- 공휴일/자료 부족 등의 긴 문구와 장기 사용자 테스트.
- 초기 연결 실패의 재시도 UI와 결산 기록 복원은 별도 작업.

## 글꼴·간격 정돈

- Pretendard 1.3.9 가변 글꼴을 로컬 번들에 포함했다. 외부 폰트 CDN에 의존하지 않는다. 폰트 원본은 약 2.06MB이며 OFL 라이선스 사본은 `public/licenses/Pretendard-OFL.txt`에 동봉한다.
- `typography.css`로 한글·영문·숫자 글꼴, 글자 역할별 크기, 행간, 자간과 줄바꿈을 통일했다.
- 모바일의 10px 보조 문구를 12px로 올리고, 변화율 숫자의 세로 기준선을 맞췄다.
- 체크박스의 위쪽 여백을 제거하고, 정류소 이름/번호 및 날짜 라벨 간격을 정리했다.
- 주 이름·날짜 범위·입력 현황을 구분했다. 태블릿 금액 입력은 4열로 조정했다.
- 파일 선택 버튼의 글꼴을 통일하고, 로딩 설명의 중복 문장과 강제 줄바꿈을 줄였다.
- 긴 가게 이름 검수 상태를 추가했다. 5개 상태 × 5개 너비(320/390/820/1024/1440px)의 25개 조합에서 페이지 가로 넘침 및 주요 제목/설명/기간 문구의 가로 잘림이 없었다.
- 모바일의 두 변화율 숫자 상단 좌표가 같음을 확인했다. 질문창은 본문 14px/행간 24.5px이며 문서 너비 안에 표시된다.
- 정상·자료 부족·긴 문구·질문창·로딩의 브라우저 시각 점검을 수행했다. 실제 기기 키보드 및 A4 인쇄는 별도 검증 대상이다.
