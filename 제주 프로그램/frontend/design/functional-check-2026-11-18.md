# 전체 동작 점검 — 2026-11-18

기존 자료와 분리한 가상 DB와 포트 8768의 실제 EXE로 검사했다. 기본 디자인 테스트 앱(8767)의 가게/매출 자료는 변경하지 않았다. 프론트엔드에서 발견한 문제 2개를 수정했고, 백엔드 동작 코드는 변경하지 않았다.

## 자동 검사

- 프론트엔드: 5개 파일, 19개 테스트 통과. TypeScript 검사와 프로덕션 빌드 성공.
- 서버: 92개 테스트 통과. 계산, 저장/삭제, 검증, 업로드, 결산 작업/취소, 질문 범위, 세션 분리와 수집 정책 등을 포함한다.
- 서버 첫 시도는 기존 임시 경로의 권한 문제로 일부 fixture 생성에 실패했다. 작업 폴더 안의 새 임시 경로와 캐시 비활성화 설정으로 전체 재실행하여 통과했다.
- 서버 테스트에서 의존성의 비차단 deprecation 경고 1개가 있었다. 이번 범위에서는 의존성을 변경하지 않았다.

## 발견하고 수정한 문제

1. 매출 화면 아래에서 결산을 만들면 이전 스크롤 위치가 남아 제목이 가려졌다. 결산 페이지 진입 시 위쪽으로 이동하도록 수정했다. 실제 EXE에서 제목 위치가 화면 밖(-369px)이던 상태가 해소됐고 스크롤 0으로 진입함을 확인했다. 관련 자동 테스트도 보강했다.
2. PC 하단의 ‘내 자료 지우기’가 떠 있는 질문 버튼에 가려졌다. 자료 관리를 왼쪽에 두고 결산 화면 하단 공간을 확보했다. PC와 모바일에서 확인창 열기/취소를 직접 재검사했고 버튼 겹침이 없었다.

기본 테스트 앱과 기능 검사 앱 모두 수정한 EXE로 재시작했다.
