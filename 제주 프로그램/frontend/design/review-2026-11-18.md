# 디자인 검수 — 2026-11-18

현재 디자인의 큰 구조는 유지했다. 막대그래프, 날짜 아래 수치, 실제 비교 기준 문구와 접는 결산 패널을 중심으로 검수했다.

## 검증

- 설정, 매출 입력 최초/자료 부족, 공개 자료 준비 상태, 정상 결산, 긴 가게 이름, 비교 자료 부족의 6개 상태.
- 320, 390, 686, 820, 1280, 1440px의 6개 너비. 총 36개 조합에서 문서 가로 넘침 및 자동으로 열린 결산 모달 없음.
- 그래프 높이는 각 너비에서 220~320px이며 날짜/막대 정렬과 변화율 표시는 유지했다.
- 브라우저에서 PC→모바일 전환, 날짜 선택, 패널 열기/닫기, 모바일 패널에서 질문창 전환을 확인했다. 최종 검수 탭의 오류 로그 없음.
- 프론트엔드 테스트 18개 통과. 창 크기 전환으로 모달이 자동으로 열리지 않으며 날짜 선택을 유지하는 회귀 테스트 추가.
- TypeScript 검사와 프로덕션 빌드 통과.

## 검증 범위

검수 화면은 가상 자료를 사용한다. 백엔드 계산과 데이터 계약은 변경하지 않았다. 실제 기기의 가상 키보드, A4 인쇄/PDF 페이지 분할, 실제 API 데이터 분석 정확성은 별도 검증 대상이다.

이번 결과는 소스와 개발 검수 화면에 반영했다. 이전 EXE와 2026-11-17 소스 ZIP은 이 검수 전 버전이다. GitHub에는 2026-11-18 소스 묶음을 사용한다.

## 후속 여백 정리

- 카드와 사이드바의 안쪽 간격, 카드 사이 간격, 제목 아래 간격을 줄였다. 글자 크기와 날짜 아래 퍼센트 표시는 유지했다.
- 그래프 높이를 190~260px로 압축하고, 표시 범위도 실제 증가/감소의 상하한에 맞췄다. 두 시리즈에 동일한 단위 길이를 사용하며 빈 위쪽 범위만 줄였다.
- 정상/긴 문구/자료 부족 상태를 320/390/686/820/1440px에서 확인했다. 15개 조합에서 가로 넘침이 없었다.
- 증가와 감소의 같은 변화율이 같은 막대 길이로 표시되는 회귀 테스트를 추가했다. 빌드와 테스트 19개 통과.
- 후속 수정 소스 묶음 이름에는 `compact`를 붙여 앞선 묶음과 구분한다.

## 가벼운 컬러 배너 적용

- 상단 로고 영역에 옅은 청회색 배경과 직접 작성한 SVG 곡선 패턴을 적용했다. 실물 사진, 생성 이미지나 외부 이미지 요청은 사용하지 않는다.
- 바깥 배경은 청회색, 작업 카드와 그래프는 흰색으로 구분한다. 주간 결산 요약에만 옅은 파란색을 더했다.
- 배너 높이는 기존 62/72px로 유지했다. 패턴은 장식 요소로 처리하여 클릭과 접근성 읽기 순서를 방해하지 않는다.
- 모바일 주간 요약의 두 수치는 각각 라벨 아래 같은 위치에 배치한다.
- 설정/매출 입력/정상/긴 문구/자료 부족의 25개 화면 크기 조합에서 가로 넘침 없음을 확인했다. 빌드와 기존 테스트 19개 통과.
- 최신 배너 버전 소스 묶음은 `banner`로 구분한다.

## 색 겹침 보정

- 푸른 바깥 배경과 푸른 요약 카드의 색이 겹쳐 경계가 흐릿하다는 피드백을 반영했다.
- 바깥 배경은 중립 회색, 주간 요약은 흰색으로 구분하고 얇은 파란 왼쪽 선만 포인트로 남겼다. PC 사이드바 주간 요약도 같은 원칙으로 맞췄다.
- 상단 청회색 배너와 추상 곡선은 유지했다. 비교 기준·기간·라벨의 회색을 더 짙게 조정했다.
- 타입 검사와 프로덕션 빌드 통과. 최신 소스 묶음은 `contrast`로 구분한다.

## 청회색과 반투명 표면

- 후속 선호에 맞춰 바깥 배경을 청회색으로 되돌리고, 옅은 색 번짐으로 깊이감을 더했다.
- 요약·상세 카드와 사이드바에 반투명 흰 표면, 얇은 밝은 테두리와 약한 그림자를 사용했다. 상단은 배경이 살짝 비치는 고정 배너이다.
- 그래프 영역은 약 94% 불투명도로 유지하여 눈금·막대·숫자가 배경에 묻히지 않게 했다. 글씨 자체의 불투명도는 낮추지 않았다.
- backdrop-filter를 지원하지 않는 환경에는 밝은 단색 카드로 대체하고, 인쇄에서는 그림자와 투명 효과를 해제한다.
- 이번 변경은 시각 스타일이며 계산·API·날짜 선택 동작은 변경하지 않았다. 타입 검사와 빌드 통과. 최신 소스 묶음은 `glass`로 구분한다.
