# 현재 결산 화면 구성

2026-11-18 기준. React/TypeScript 프론트엔드의 디자인과 검수 기록입니다. 최신 보완 내용은 [디자인 재검수](review-2026-11-18.md)에 정리했습니다.

## 그래프와 비교 기준

- PC, 태블릿, 모바일 모두 큰 세로 막대그래프로 7일의 가게/동네 변화율을 비교합니다.
- 파란색은 가게 매출, 회색은 동네 이용 지표입니다. 두 지표와 모든 날짜에 동일한 축을 사용합니다.
- 왼쪽의 큰 축 숫자는 제거했습니다. 요일 목록 위 왼쪽에 ‘그 전 4주 같은 요일 대비 · 기준선 0%’를 작게 표시합니다.
- 증가만 또는 감소만 있는 주에는 해당 방향으로 축을 확장하고, 양쪽 변화가 있으면 0%를 중앙에 둡니다.
- 날짜 아래 두 줄로 변화율을 표시합니다. 모바일은 정수로 반올림하고, 날짜를 누르면 상세 영역에서 소수점 수치를 확인합니다.
- 자료 없음은 대시와 ‘비교 불가’로, 실제 0%는 숫자와 기준 위치의 짧은 표시로 구분합니다.
- 전체 숫자 표는 ‘요일별 수치 보기’로 접어둡니다. 시간대 데이터와 전일 대비 계산은 추가하지 않았습니다.

## 결산 패널과 반응형

- 1280px 이상은 오른쪽 결산 사이드바입니다. 접으면 그래프 영역이 넓어지며 다시 열어도 날짜 선택을 유지합니다.
- 1280px 미만은 모달 패널, 760px 이하는 하단 시트입니다. 본문에도 압축한 주간 결산 요약을 표시합니다.
- 선택 날짜의 변화율, 강수량, 공휴일, 비교 제외 사유는 기존 API 응답을 사용합니다.
- 모바일 패널 닫기와 Escape를 지원하며, 닫으면 스크롤과 열기 버튼 포커스를 복구합니다. 질문 버튼은 기존 질문창으로 연결됩니다.
- 하단 결산/질문 버튼의 겹침을 해소하고 안전 영역을 반영했습니다. 패널 닫기 버튼은 최소 44px입니다.
- 지표별 상세 표와 날씨/출처 근거, 인쇄용 요약을 유지합니다.

## 검증 기록

- 프론트엔드 5개 테스트 파일, 17개 테스트와 TypeScript 검사 및 프로덕션 빌드 통과.
- 전체 검수에서는 설정/매출 입력/자료 준비/정상 결산/긴 문구/자료 부족의 6개 상태를 320/390/686/820/1280/1440px에서 확인했습니다. 문서 가로 넘침과 하단 버튼 겹침은 없었습니다.
- 그래프 중심 재배치 후 정상/긴 문구/자료 부족을 320/390/686/820/1440px에서 확인했습니다. 날짜 선택과 수치 표 펼치기/접기도 확인했습니다.
- 최신 기준 문구와 날짜별 수치 표시는 별도 테스트 EXE에서도 확인했습니다. 이 EXE의 매출·동네 지표·날씨는 모두 가상 자료이며 GitHub 소스 묶음에 포함하지 않습니다.
- 실제 기기의 가상 키보드와 안전 영역, 인쇄/PDF 페이지 분할은 별도 검증 대상입니다. 이 검수는 실제 수집 데이터의 분석 정확성을 보증하지 않습니다.

## 제거한 장식 이미지

초기 시안에 사용한 제주 해안 이미지는 결산 내용과의 관련성이 약해 화면과 소스 배포 대상에서 제거했습니다. 원본은 로컬 `runtime/design-archive/jeju-coast.png`에 보관하며 Git에서 제외합니다.

제작 방식은 내장 imagegen의 새 이미지 생성입니다. 프롬프트는 ‘긴 가로 구도, 앞쪽 현무암 담, 채도를 낮춘 청회색의 잔잔한 제주 바다와 밝은 흐린 하늘, 사람·건물·배·문구·로고 없는 차분한 사진 느낌’이었습니다. 실제 가게의 위치 사진이 아닙니다.
