# 데이터 활용 명세

| 항목 | 내용 |
|---|---|
| 주제 | 제주 버스 노선·시간대 수요 분석 에이전트 |
| 데이터 후보 | 전달받은 데이터명세서_kr.xlsx (2026-11-04 v13) 기준 3-02 버스 노선별 이용 현황, 3-04 버스 정류소별 이용 현황 |
| 3-02 명세상 필드 | `base_date`, `day_of_week`, `base_hour`, `bus_route_id`, `bus_route_name`, `get_on_off_type`, `user_category`, `user_count` |
| 3-04 명세상 필드 | 날짜/시간, 정류소, 승하차 유형, 이용자 구분, 이용자 수. 정확한 컬럼명은 원시 자료 확인 후 매핑 |
| 출처/이용 조건 | 참가자 전용 데이터명세서에서 반출 가능으로 확인되었다는 전달 내용. 세부 출처 URL·라이선스/반출 조건은 미확인; 실자료 이용 전 공식 확인 필요 |
| 실제 사용 여부 | 미연동. 원시 자료 미수령. 저장소에는 실제 데이터가 없음 |
| 시연 데이터 | `data/sample_bus_routes.csv`, `data/sample_bus_stops.csv`: 에이전트 동작 확인을 위해 만든 합성 자료. 실제 제주 통계가 아님 |
| 수집·전처리 | 허용 조건 확인 → 원시 컬럼·형식/기간/분류 검증 → 누락·중복 검사 → 질문 기준으로 `user_count` 합산. 실자료 확보 후 세부 절차 문서화 |
| 분석 흐름 | 질문 → 노선/정류소 데이터 선택 → 요청 차원별 이용자 수 합계 → 표·차트·요약 및 출처·한계 표시 |
| 제외 범위 | 5-02 일일 날씨 정보는 후속 연동 후보이며 현 MVP에서 사용하지 않음. 혼잡률·혼잡 예측·최적 배차 분석을 하지 않음 |

## 주의

- 참가자 전용 데이터 목록(xlsx)과 실자료는 저장소에 커밋·공개하지 않는다(`*.xlsx`, `data/private/` 무시).
- 실자료 이용 전 공식 이용조건과 반출 허용 범위를 확인한다.
- `user_count`는 태그 기반 이용자 집계이지 차량 정원·잔여 좌석이 아니다. 혼잡률이나 혼잡 예측으로 해석하지 않는다.
- 명세서 파일 자체나 미확인 원시 데이터의 통계·값을 복제·추정하지 않는다.

streamlit, pandas, python-dotenv (선택: openai). AI/외부 자원 상세는 `ai-usage-and-external-resources.md` 참고.
