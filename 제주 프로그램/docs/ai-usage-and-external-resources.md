# AI 사용 및 외부 자원

## AI 모델과 사용 범위
| 제공자 | 모델 | 위치 | 용도 |
|---|---|---|---|
| mock (기본) | 없음 | 로컬 | 분석 결과를 그대로 요약, 테스트용 |
| ollama (선택) | 예: llama3.1:8b (소형, 센터 PC 실행 가능) | 로컬 | 분석 결과의 쉬운 한국어 요약 |
| openai (선택) | 예: gpt-4o-mini | **외부 API** | 동일 용도, 사용 시 외부 의존 명시 필요 |

AI는 요약 문장 생성에만 사용하며, 수치 계산은 pandas가 수행한다. 에이전트 자율성 범위: 데이터셋 선택·집계·요약(읽기 전용, 파일 수정·외부 전송 없음).

## 외부 API
기본 구성은 없음. openai 선택 시에만 요약용 집계 문장이 외부로 전송됨(원본 데이터 미전송).

## 오픈소스
streamlit, pandas, python-dotenv, (선택) openai SDK.

## 보안
API 키는 `.env`(미커밋)로만 관리, 개인·금융·인증 정보는 코드에 포함하지 않음.
