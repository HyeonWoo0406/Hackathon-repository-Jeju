# 사용자 매뉴얼

## 설치
1. Python 3.10+ 설치
2. `pip install -r requirements.txt`
3. `copy .env.example .env` (기본값 `LLM_PROVIDER=mock`)

## 사용
- 화면: `streamlit run app.py` → 버스 이용량 질문을 입력하고 "분석하기" 선택
- CLI: `python cli.py "요일별 노선 이용량을 보여줘"`
- 예시: `python cli.py "정류소별 하차 이용자 수"`, `python cli.py "이용자 유형별 이용량"`
- 결과: 요약, 그룹별 이용자 수 표·차트, 데이터셋 출처, 자료 종류, 해석 한계

`노선`이 포함된 질문은 노선별 이용 현황, `정류소` 또는 `정류장`이 포함된 질문은 정류소별 이용 현황을 선택한다. 시간대·요일·승하차·이용자 유형 관련 단어로 집계 기준을 정할 수 있다. 현재 MVP는 그룹 기준 집계만 하며 자연어 날짜 범위나 임의 조건 필터링은 지원하지 않는다.

## 재현
같은 CSV와 `LLM_PROVIDER=mock`이면 집계 결과가 항상 동일하다. 기본 CSV는 합성 시연 자료이며 제주 버스의 실제 이용량을 나타내지 않는다.

## 오류 및 한계
- CSV 경로 오류: `src/data_loader.py`의 `CATALOG` 경로 확인
- ollama 연결 실패: ollama 실행 여부와 `OLLAMA_URL` 확인
- 실자료는 반출·이용 조건을 확인한 후 `data/private/`에서 별도 관리하고 저장소에 커밋하지 않는다.
- 이용자 수는 태그 기반 집계다. 차량 정원·잔여 좌석이 없으므로 혼잡률·혼잡 예측·최적 배차는 제공하지 않는다.
- 현재 합성 CSV는 시연용이며 실제 기간·표본·누락값을 반영하지 않는다.
